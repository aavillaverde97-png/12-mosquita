⚙️ Configurar Firebase

El objeto firebaseConfig en el código todavía tiene los valores de ejemplo.

Pasos rápidos:
1. Ir a console.firebase.google.com
2. Crear proyecto → Build → Realtime Database → "Start in test mode"
3. ⚙ → Project settings → agregar app web (</>)
4. Copiar el objeto firebaseConfig y pegarlo en el código
5. En Rules de la DB pegar: {"rules":{".read":true,".write":true}}
